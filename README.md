# No-Code Website Builder (Test Prototype)

A single-page no-code website builder prototype — a visual experiment in building simple websites without writing code. Built as a testbed for AI-assisted website generation ideas.

## Features

- **Visual builder interface** — drag-and-drop style page composition
- **Live preview** — see changes instantly as you build
- **Exportable output** — generates usable HTML
- **Fully client-side** — no backend, no accounts, no build step

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Quick Start

No build step required:

```bash
npx serve .
# or
python3 -m http.server 8000
```

Open `http://localhost:8000`.
